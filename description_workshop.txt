[h1]Slope Collision Fix (macOS/Linux ARM64)[/h1]

Fixes hammered (sloped) block stairs acting like walls on [b]Apple Silicon Macs[/b] and other [b]ARM64[/b] systems.

[h2]The bug[/h2]
On ARM64, when you walk from a flat floor into a sloped block, the player stops dead as if the slope were a wall instead of walking up it. Regular step-up stairs still work.

The problem shows up with popular mods such as [b]Calamity Mod[/b] or [b]Magic Storage[/b] enabled, because they hook the collision code, but [b]the root cause is not in those mods[/b].

[h2]What is going on[/h2]
The optimized machine code that .NET's JIT compiler generates for Terraria's [i]Collision.TileCollision[/i] on ARM64 gets the sloped-tile check wrong. The same C# code with the same inputs returns the correct result when it is not optimized. Mods that hook [i]TileCollision[/i] make it happen right away, because the hooked copy is compiled with full optimizations.

[h2]What this mod does[/h2]
It installs one hook on [i]Collision.TileCollision[/i] that runs an exact, unoptimized copy of the vanilla method instead of the miscompiled one. Hooks other mods placed on [i]TileCollision[/i] are replayed on top of that copy in the same order, so their behavior is kept. Calamity Mod's arena walls and Magic Storage's Storage Unit collision are supported.

[h2]Safety[/h2]
[list]
[*]Only changes [i]Collision.TileCollision[/i]. It does not touch worlds, players, items or network packets, and saves no data. Removing it leaves no trace.
[*]Turns itself off, so the game behaves as if the mod were not installed, if:
[list]
[*]the system is not ARM64 (configurable),
[*]tModLoader's [i]TileCollision[/i] differs from the version this copy was written for,
[*]another mod changes [i]TileCollision[/i] in a way that cannot be replayed exactly,
[*]hooks change while the game is running.
[/list]
[*]Does not need to be installed on the server or by other players (NoSync).
[/list]
Every decision is written to [i]client.log[/i] under [b][SlopeCollisionFix][/b].

[h2]Config[/h2]
[b]Activation:[/b] Auto (ARM64 only, default), Always, Never. Try [b]Always[/b] if you see the same bug on another platform, and please report it.

[h2]Compatibility[/h2]
Tested on macOS (Apple Silicon) with Calamity Mod and Magic Storage. Not yet tested on Linux.
